Sponsor detection AI

Transcripts of the videos you watch are sent to the selected AI for analysis. Beyond that, only the anonymous diagnostics described under Privacy below ever leave your browser.

Your key is stored locally in this browser and sent only to the provider you selected.

Usage

SponsorBlock

Use the community-run SponsorBlock database for instant, exact segment skipping on videos others have already marked. The AI above only runs when SponsorBlock has nothing. Privacy-preserving: your video is looked up by a hashed prefix, so the server never learns which video you watched.

Skipping behavior

YouTube extras

Optional annoyance removers. Each is off by default.

Filter rulesets

Each blocking list is a set of network rules. Turn them on or off individually here. Loaded is how many rules Chrome currently has active — if a list is on but shows nothing loaded, Chrome hit its per-session rule limit; restart the browser to clear it.

Ad blocking

Sites where ad blocking is paused. Add sites here, or use the popup's “Pause ad blocking here” toggle while on a site.

    Analysis cache

    Sponsor analysis is cached per video so a re-watch never re-runs the AI. Clear it to force fresh analysis (e.g. after changing provider).
